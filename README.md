## 🌟 Overview

This is the official production website for **DevotedZen Labs**, a deep-tech AI startup based in Maitidevi, Kathmandu, Nepal building specialized perception and intelligence engines.

### Flagship Products Showcased:
1. **SadakDrishti (सड़क दृष्टि)**: Autonomous computer vision for road infrastructure inspection, real-time pothole/crack detection, and ASTM D6433 Pavement Condition Index (PCI) calculation.
2. **AI Cyber Threat Intelligence (ZenShield CTI)**: Predictive enterprise cybersecurity platform featuring dark web breach surveillance, zero-day threat correlation, and automated MITRE ATT&CK kill-chain mapping.
3. **AI Fitness Tracker (ZenFit)** *(In Active Creation)*: Camera-first, zero-hardware digital coach with 33-point real-time 3D pose estimation, biomechanical joint angle tracking, and automated rep counting.

---

## 🚀 Live Interactive Simulators Included

The website includes three high-fidelity, real-time client-side simulators:
- **Road Anomaly Perception Canvas**: Simulates highway dashcam footage with 3D perspective road animation, moving vehicles/hazards, bounding boxes with confidence scores, GPS coordinates, and weather modes (Day, Rain, Night).
- **SOC Threat Intelligence Command Terminal**: Streams simulated live threat indicators of compromise (IOCs), threat actor attribution, and interactive IOC enrichment tool.
- **Biomechanical 33-Keypoint Pose Tracker**: Canvas-rendered procedural stick-figure skeleton executing squats with live joint angle arcs, rep counter, and real-time posture correction cues.

## 💻 How to Run Locally

### Option 1: Direct File
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
